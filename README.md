# Lab 05 - Reliable Data Importer

Лабораторна робота №5. Варіант 4 — Система банківських рахунків.
Реалізовано надійний модуль імпорту/експорту з обробкою помилок, логуванням, streaming I/O та атомарним записом.

## Запуск
1. Встановіть залежності: `pip install pyyaml`
2. Запустіть: `python src/reliable_importer/main.py`
